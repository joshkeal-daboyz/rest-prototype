# City style guide

This guide has been split into one file per domain, under `docs/city-style/`. Start at [`docs/city-style/index.md`](city-style/index.md): it maps every old section number to its new file and says which agent reads which.

The text moved verbatim (ticket 080 section A). The sections keep their old numbers, so links in old tickets and handoffs that name "section 16.10" or "chapter 18" still resolve through the index.

The Numbers table, which `src/render3d/styleguide.test.ts` checks against the code, is `docs/city-style/numbers.md`.
