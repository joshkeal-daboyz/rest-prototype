## How the loop runs (what worked)

1. **Cut**: `lead-architect` writes `tickets/NNN-*.md` (it also edits docs/guide; one agent can be resumed with SendMessage but a new session starts fresh: pass it the ticket path). Show Josh a few lines; his chat word approves.
2. **Build**: one worktree per ticket section from `goal/city-style`:
   ```powershell
   cd D:\rest-prototype-goal; $d="D:\rest-prototype-XXX"; git worktree add -b ticket/XXX-slug $d goal/city-style
   cmd /c mklink /J "$d\node_modules" D:\rest-prototype-main\node_modules
   New-Item -ItemType Directory -Force "$d\assets\private"
   cmd /c mklink /J "$d\assets\private\out" D:\rest-prototype-main\assets\private\out
   cmd /c mklink /J "$d\assets\private\calibration" D:\rest-prototype-main\assets\private\calibration
   ```
   Spawn the `renderer` agent (src/render3d/ and the guide) with the ticket path, the worktree, the branch, Josh's quoted words, "tests CI-safe, ladder unchanged (townpin.test.ts), no loosening of thresholds, vitest `--maxWorkers=2`, no browser, do not merge/push, **report in the FINAL plain-text message, not a SubagentHandback call (those get refused)**". At most two builders at once, in files that do not overlap.
3. **Gate** (you, not the builder), in the detached worktree `D:\rest-prototype-gate`:
   ```bash
   cd /d/rest-prototype-gate && git checkout -q -f --detach <commit> && rm -f gate-out.txt && (powershell -NoProfile -Command "Start-Process -FilePath cmd.exe -ArgumentList '/c','npx tsc --noEmit && npx vitest run --maxWorkers=2 > gate-out.txt 2>&1 && echo GATE_OK >> gate-out.txt' -WorkingDirectory 'D:\rest-prototype-gate' -WindowStyle Hidden")
   ```
   then wait with an until-loop in a background command and read `tail gate-out.txt`. Red gate or a test count that did not grow goes straight back to the builder.
4. **Review + playtest**: spawn `code-reviewer` (writes `reviews/NNN-slug.md`, `must-fix: N`) and `playtester` (writes `playtests/NNN-slug.md`, `regressions: N`) together, each given only ticket, branch, commit and where the gate worktree is; tell the playtester to write into `D:\rest-prototype-gate\playtests` (one wrote into the wrong checkout once). Max two rounds, then take it to Josh as it stands. Copy the review/playtest files into the section's worktree and commit them there.
