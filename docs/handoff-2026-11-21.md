## How the loop runs (commands that work)

**Worktree:**
```
git worktree add -b ticket/<slug> D:\rest-prototype-<id> <commit>
cmd /c mklink /J D:\rest-prototype-<id>\node_modules D:\rest-prototype-main\node_modules
New-Item -ItemType Directory -Force D:\rest-prototype-<id>\assets\private
cmd /c mklink /J D:\rest-prototype-<id>\assets\private\out D:\rest-prototype-main\assets\private\out
cmd /c mklink /J D:\rest-prototype-<id>\assets\private\calibration D:\rest-prototype-main\assets\private\calibration
```

**Gate.** Run in PowerShell, then read the last "Test Files" and "Tests" lines; the echoed exit code is unreliable.
```
if (-not (Test-Path D:\rest-prototype-gate\.git)) { throw }; Set-Location D:\rest-prototype-gate -ErrorAction Stop; git checkout -q -f --detach <commit>; Remove-Item -ErrorAction SilentlyContinue gate-out.txt; $p = Start-Process -FilePath "cmd.exe" -ArgumentList '/c','(npx tsc --noEmit && npx vitest run --maxWorkers=2) > gate-out.txt 2>&1 & echo exit %errorlevel% >> gate-out.txt' -WorkingDirectory D:\rest-prototype-gate -WindowStyle Hidden -PassThru; $p.PriorityClass = 'BelowNormal'; $p.WaitForExit()
```

1. Run a background PowerShell `HttpListener` on `http://localhost:5300/` that saves the posted body (a data URL) to `<scratchpad>\<name>.png` and stops on `?name=stop`.

3. `fetch('http://localhost:5300/?name=...', {method:'POST', mode:'no-cors', body:url})`.
